    Development boundaries
    Optional structured AI suggestions require a configured HTTPS provider, an authenticated writable workspace credential and a positive budget. No shell tool, browsing connector, outbound messaging, purchases or live billing. Workspace API credentials support owner/operator/viewer roles; this is a pilot foundation, not a complete customer identity platform. Approval binds to the stored immutable plan hash. Failed tasks require a new reviewed request; automatic retries and in-flight cancellation are not supported.
